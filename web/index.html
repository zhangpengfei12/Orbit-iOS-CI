一、快速上手
  1. 首次进入会提示试用 15 天：点「开始试用」才开始计时，到期后仍可进首页，点具体功能才弹激活面板；面板里可直接复制机器码、查看客服微信号与客服二维码。
  2. 在「设置 → 媒体库」添加本机或 SMB 网络共享的视频目录，等待扫描完成。
  3. 在「设置 → 设备」选择连接方式（USB 串口 / 蓝牙串口 / WiFi-UDP），保存后点「连接测试」确认设备可达。
  4. 在「设置 → OSR 轴设置」按你的设备校正各轴方向与行程范围。
  5. 返回首页点「视频库」进入媒体库，打开影片即可播放；同目录同名的 .funscript 会自动加载并跟随。
二、媒体库与视频

媒体库支持本机目录与 SMB 网络共享（如 NAS）。进入后按目录浏览，视频以列表展示。点开影片即进入播放页；同目录若存在同名 .funscript 脚本，会自动关联并在播放时同步驱动 OSR 设备。

首页「视频库」即你的媒体库入口，点卡片进入；面包屑可逐级返回，根目录显示为「手机存储」。选完视频若要存脚本，会自动弹文件夹授权，选中视频所在文件夹并允许「写入」即可。

三、连接 OSR 设备

在「设置 → 设备」中选择一种连接方式：

  • USB 串口：手机经 OTG 直连设备，点「检测 USB 设备」并选择串口（同时兼容 USB 驱动板与 CDC-ACM 设备）。
  • 蓝牙串口：点「蓝牙扫描」配对 SPP/GATT 设备，选中后连接；蓝牙需先配对再选择。
  • WiFi（UDP）：填入设备 IP 与端口（默认 192.168.1.88:8000），适合局域网或广播场景。

配置后务必点「连接测试」：成功表示链路可达；失败会提示原因（IP 不可达 / 端口拒绝 / 设备未开机等）。首页「设备」磁贴的副标题会实时显示链路状态：离线（硬件输出关闭）／待机（UDP 无回执）／已连接（有真实链路证据）／未连接／发送失败。

若设备支持「WiFi 配网」：手机连上设备发出的热点（名称 SR6-Config、密码 12345678），按提示在浏览器打开 192.168.4.1，填入家里 2.4G 频段的 Wi-Fi 名称与密码即可完成配网；配网必须用 2.4GHz 频段的 Wi-Fi，5GHz 频段的 Wi-Fi 不支持。

四、OSR 轴设置

按设备型号校正 6 个轴的方向（正向 / 反向）与行程范围，避免驱动时方向错误或超程。设置保存后立即生效，后续脚本与自动模式都会沿用。

两个补偿开关（默认都是关闭，任一改动都会一起提交）：

  • 旋转补偿（作用于 R0）：关闭 / 跟随L0（用 L0 的轨迹驱动 R0）／循环摆动（按固定幅度往复）。
  • 俯卧补偿（作用于 R1）：关闭 / 循环摆动；任何脚本不含 R1 轴时会自动按设定幅度注入。

点「恢复默认值」会立即把两个补偿都重置为关闭、幅度恢复默认并落库；只刷新界面数字不落库等于没改。

五、脚本播放

在「脚本播放」页选择已加载的 .funscript 脚本，可预览轴轨迹（可视化曲线）并播放，支持多轴同步，配合影片时间轴精准跟随。

多轴脚本的文件命名：主脚本与视频同名，另加后缀 .<轴>.funscript，轴名可取 L0/L1/L2（上下、左右、翻滚）与 R0/R1/R2（旋转、俯仰、翻滚）。多个轴文件放在视频同目录即可自动识别。

六、AI生成脚本

影片没有脚本时，可以用「AI生成脚本」自己生成一份。点「选择视频」挑一个视频，调好参数后点「开始生成」即可，不需要先授权文件夹。

默认参数已经把动作幅度调得比较大（强度灵敏度 1.8×、平滑 25%），要更柔可以直接把「强度灵敏度」往下拖；脚本优先写在视频同一个文件夹；那个文件夹还没授权写入时，会自动存到应用私有目录，播放时按视频名自动匹配，功能完全一样。如果你希望 .funscript 就落在视频旁边，点「授权保存到视频旁」一次即可，之后同目录不再问。

生成用的是音视频混合流：画面运动决定什么时候动、往哪个方向动，音频的低频能量决定这一下使多大劲，再把它们合成一串有起有落的往返动作。三个最常调的参数：笔触频率上限（设备跟不上的高频往复要压掉，一般 3–5 Hz）、强度灵敏度（整体行程大小）、平滑强度（相邻笔触的力度是否均匀）。若感觉画面已经动了设备才动，把设备延迟补偿往正方向调。

生成结果会缓存：若当时没授权，可先生成再补授权，随后用「改存到视频旁」一键落盘，不必重跑分析。

脚本会写成与视频同名的 .funscript 放在视频旁边，回「视频库」打开该视频即会自动加载并跟随；已有同名脚本会被覆盖。

七、脚本编辑（随播录制）

「脚本编辑」= 边看片边录轨迹：选一个视频后自动跳进播放器（横屏整屏录制台），用播放器右缘的 L0 浮动滑块上下拖动即可实时驱动设备，R0 + R1 固定 50%；录制时按视频播放时间轴采样 L0，停止后保存到视频同目录，下次打开该视频自动跟随。退出录制台会顺手把设备送回中位。

  • 倍速：录制前在弹窗里选 0.25 / 0.5 / 0.75 / 1 倍，慢放录出来动作更细腻。
  • 范围：设定这轮录制允许的行程区间，超出部分会被夹住。
  • 界面分层为顶栏（返回 + 录制按钮、倍速与范围）、右缘 L0 竖滑块、底部波形与录制时间，窄屏横屏也互不遮挡。

录完点左上角返回即可；录制台内不会再弹试用胶囊等界面。

八、手控触板与姿态
  • 手控触板：拖动各轴圆点实时驱动设备，可把操作轨迹录成 .funscript 保存。
  • 姿态（陀螺仪）：靠手机陀螺仪驱动。tiltA 是倾角（手机前倾 / 后仰）；tiltB 是摇一摇（竖向摇 → L0，横向摇 → R0 + R1）。

两面板互斥：同时只能有一个在接管驱动，打开其中一个会自动退出另一个。

九、自动模式

按一套固定节奏自动动，三个参数：

  • 速度：节拍 20–180 BPM（默认 60），设备跟得上就往上加，跟不上会被截顶。
  • 强度：行程比例 20%–100%（默认 80%），小幅度更柔和、大幅度更有力。
  • 动作时长：单次 3–30 秒（默认 8 秒）。
  • 切换：关掉自动切换后，动作会锁在当前设置不再轮替。

运行中可直接切模式，系统会自动停掉当前模式再按新模式启动，不用先手动停止。

十、VR 一体机与 VR 盒子

在「VR 一体机」页连接外部 VR 播放器（DeoVR / HereSphere）。连接后，影片时间轴作为统一时间源，OSR 脚本与之对齐，实现“视听 + 体感”同步。首页「VR盒子」则是用手机放进 VR 眼镜盒里看，两者互不影响。

十一、切到后台也要继续跑

播放影片或运行自动模式时切到后台（甚至锁屏），设备会继续跟随 —— 靠的是多层配合：播放时钟在原生侧按系统时间自驱（不依赖网页的定时器）、前台服务 + 唤醒锁（进程不被冻结、息屏后 CPU 与 WiFi 不被降频）、兜底闹钟（服务万一被回收会自动拉回）、页面被告知"已在后台"（视频被系统静默暂停时也不会误报「已暂停」）。

国产 ROM（小米 / 华为 / OPPO / vivo 等）还有一层独立的「后台耗电管理 / 自启动管理」，比前台服务更强，没进白名单照样会被冻结。请到「设备」页找到后台运行卡片，点「允许后台运行」把本应用加入电池优化白名单；若仍被限制，再到系统设置的「电池 → 后台耗电管理」里把 Orbit 设为「无限制 / 允许后台活动」。

十二、试用与激活
  • 首次进入可试用 15 天，点「开始试用」才开始计时；到期后是软拦截——还能进首页，点功能才弹激活面板。
  • 激活流程：复制机器码 → 发给客服微信号 yeee9991（或扫客服二维码）→ 拿到卡密 → 贴回输入框点「激活」。
  • 卡密绑定设备，共 116 个字符，必须以 ORB1- 开头；整段复制，别改大小写，注意 0 与 O、1 与 I/l 的区别。粘贴时会自动去掉换行和多余空格。
  • 同一张卡只能绑一台机器：换机要用新机器码找客服换卡。
  • 卡已过期可以找客服续期；客户端会先做本机自检（长度、前缀、签名），提示「signature 不对」时优先比对字符有没有被改动或截断。

已知硬边界（本地方案只能做到这样）：Root / Magisk、改过安装包、模拟器、应用双开多用户、开了 WebView 调试，都可能绕过校验。

十三、在线更新

「版本信息」页的检查更新 / 立即更新是同一个按钮：没发现新版时显示「检查更新」，发现新版后变成「立即更新」，点一下就下载 APK 并安装（主源为腾讯云静态托管，失败自动降级 GitHub Releases）。下载完成会先校验完整性再交给系统安装，中途可在同一按钮看到进度。

「版本信息」页会列出真实发过的全部版本与更新点，更新记录里出现的每个版本号都对应一个正式包。

十四、常见问题
  • 首页显示"离线"：尚未连上设备，先到「设备」完成连接测试。
  • 蓝牙已连接但发不出指令：设备已配对却未真正建立 SPP 链路，重扫并重新选择设备。
  • 指令无反应：确认连接方式、IP / 端口与设备端一致。
  • 脚本不跟随影片：检查影片与 .funscript 是否同名同目录；多轴脚本还要看轴后缀对不对得上。
  • 配网配不上：绝大多数是 Wi-Fi 频段问题 —— 必须用 2.4GHz 频段的 Wi-Fi，5GHz 频段的 Wi-Fi 不支持配网；配完确认手机连的是配好网后的那个网络。
  • 配网页打不开（连接超时 / 页面没有加载出来）：确认已连上设备热点 SR6-Config（密码 12345678），且地址栏是 192.168.4.1；页面会给出「重试」与「用系统浏览器打开」两个出口。
  • 提示「需要授权保存位置」：选完视频后会自动弹出文件夹选择器，选中视频所在文件夹并允许「写入」即可；部分目录（如系统 Download 根目录）不开放写入，可把视频移到 Movies 等普通目录。
  • 生成出来的脚本太乱或太软：先降「笔触频率上限」，再调「强度灵敏度」与「平滑强度」，多生成几次对比。
  • 切到后台设备就停：先看「设备 → 后台运行」卡片是否显示"已允许"；未允许就点一下按钮加白名单。若已允许仍会停，通常是该机型的「后台耗电管理」把 Orbit 归到了智能省电，去系统设置里改成「无限制」。
  • 弹激活窗口要卡密但我买过了：把机器码发给客服微信号 yeee9991（或扫客服二维码），客服核对订单后发你 116 字符的完整卡密，整段粘回输入框即可。
  • 点「检查更新」提示 404：更新服务器上还没发布过在线更新版本，属正常状态，等发布后这里就能一键更新。
  • 自动页「网页操作」里的网站打不开：那是外部站点，打不开多半是手机当前网络访问不了它（境外站点较常见）。页面会把具体原因写在上面，可以点「重试」或「用系统浏览器打开」；换一个网络往往就好了。

本应用所有数据均保存在本机，不会上传任何服务器。
